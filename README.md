# Projeto - niveis de reservatorio dagua
📝Esse projeto foi feito para o curso ETEC agenda 11 Desmvolvimento de Sistema 1.<br>
💻O objetivo era importar a biblioteca colorama e utilizá-la em uma função de nível para mudar a cor da resposta do terminal de acordo com o nível atual.<br>
as cores foram colocas  no "case" para cada nivel de agua.<br>
